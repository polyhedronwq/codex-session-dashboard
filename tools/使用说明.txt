Codex 底栏 + 会话仪表盘 —— 使用说明
========================================

一、安装

  双击  install.cmd

  它会自动：
    1. 检查 node / python / playwright / Codex 是否齐全
    2. 缺什么就问你「要不要帮你装」，同意就自动装
    3. 不缺（或补齐后）直接装完，并启动底栏、跑一次自检

  装完后，用桌面上的「ChatGPT 仪表盘」启动 Codex。
  如果 Codex 正在运行，请先完全退出（右键任务栏图标 → 退出），
  否则新快捷方式只是把旧窗口切到前台，调试端口不会打开。


二、卸载 / 回滚

  双击  uninstall.cmd

  它会停掉底栏进程、删除快捷方式、还原 Codex 配置、删掉面板插件。
  不会动 Codex 应用本身。


三、装完是什么样

  · 对话框下方多一行：轮次 / 步数 / tok/s / token 总量 / 缓存命中
  · 点「仪表盘」打开面板：概览、统计、轨迹、代理 四个页签
  · 每条回复下方显示本轮用量


四、前提

  · Windows 10/11
  · Codex 桌面版（开发时版本 26.1111.2228.0，版本差别大时底栏可能不出现）
  · Node.js、Python 3、playwright（安装脚本会检查并协助安装）


五、常见问题

  Q: 快捷方式点了没反应
  A: Codex 已经在运行。先完全退出，再点一次。

  Q: 底栏出现了，但数字一直不动
  A: 打开 %USERPROFILE%\.codex-bar\bar.log 看最后几行，
     通常是 python 路径没对上，重跑一次 install.cmd 即可。

  Q: 又自己多开了一个 Codex 窗口
  A: 这是 Codex 的通知激活引起的，与本工具无关。
     设置 → 系统 → 通知 → 找到 ChatGPT → 关掉即可。

  Q: 想看诊断信息
  A: 运行 install.cmd 后如果自检失败，把窗口里的输出发回来。
     也可以直接跑：install.ps1 -CheckOnly
