# Codex 会话仪表盘

给 Codex 桌面版加一个**会话仪表盘面板**和一条**输入框下方的状态栏**：看轮次与步数、token 消耗、缓存命中、上下文占用，以及**这条对话占用了多少周额度**。

> **非官方项目**：与 OpenAI 无关联，未获其认可或支持。
> 通过本机调试端口读取 Codex 的会话日志与页面状态，**Codex 更新后可能失效**。

![底栏](shots/layout-final.png)

## 它解决什么

Codex 桌面版能看到「这一轮用了多少」，但很难回答另外几个问题：

- 这次工作**一共**花了多少 token？缓存命中多少？
- 上下文还剩多少空间，什么时候该开新对话？
- **这条对话吃掉了我多少周额度？**（区别于账号总量，Codex 自己的用量页才看得到）
- 刚才那一轮到底跑了哪些工具、哪个子代理在干活？

## 两个部分

### 1. 状态栏（注入到输入框下方）

```
⚡ 12 轮 47 步 · 最近 30.8 tok/s  |  🗄 4.5M tok · 缓存命中 97.1%  |  ◔ 1.71%  |  仪表盘
```

- 三项指标都能点开明细弹层；再点一次关闭，点弹层外部也关闭
- 额度是**按会话归属**的周限额占比，取自 ChatGPT 用量接口；新对话在服务端统计出来之前显示 `—`
- 底栏出现异常时会保留一个提示点，鼠标悬停看原因，不会整条消失

### 2. 仪表盘面板（Codex 标签页里的 MCP App）

| 页签 | 内容 |
| --- | --- |
| 概览 | 轮次/步数、最近一轮速度、累计 token、缓存命中、上下文占用、本会话额度 |
| 统计 | 每轮的步数、上下文长度、输入/输出、缓存命中、首 token、速度 |
| 轨迹 | 按轮次展开的工具与事件时间线 |
| 代理 | 子代理图、工作足迹、沙箱姿态、变更记录、代理间消息 |

## 环境要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 |
| Codex | 桌面版（MSIX）。**本项目在 26.1111.2228.0 上验证**，其他版本可能失效 |
| Node.js | 18+（注入器用） |
| Python | 3.10+（面板服务与指标计算，仅用标准库） |
| Playwright | `npm i -g playwright`（注入器通过它连接调试端口） |

## 安装

1. 解压发布包
2. 双击 `install.cmd`

安装器会依次：校验包内每个文件的 SHA-256 → 检查依赖（缺什么就问你要不要装）→ 安装到 `%USERPROFILE%\.codex-bar` → 注册面板插件 → 建快捷方式 → 启动底栏并自检。

装完后**用桌面上的「ChatGPT 仪表盘」启动 Codex**。若 Codex 已在运行，请先完全退出——否则快捷方式只是把旧窗口切到前台，调试端口不会打开。

升级：拿到新包后再双击一次 `install.cmd` 即可，会自动备份配置、清理已废弃文件、重启底栏与面板服务。

## 卸载

双击 `uninstall.cmd`。

会停止底栏进程、删除快捷方式、还原 Codex 配置、删除插件目录，并在结束时**自检残留**（进程 / 快捷方式 / 配置段 / 目录），有残留会返回非 0 并列出。

## 安全说明（请先读）

**本工具通过 `--remote-debugging-port` 启动 Codex，该端口没有认证。**

- 端口固定为 `127.0.0.1:9223`，只监听本机
- 但**同一台机器上的任何程序都能连上它并控制 Codex**（读取页面内容、执行脚本）
- 这是 Chrome DevTools Protocol 的固有性质，不是本项目的缺陷

因此：**只在自己的个人机器上使用**；共用机器、远程桌面暴露、或装有不可信软件的环境不要开启。不需要时用 `stop-bar.cmd` 停掉底栏并重启 Codex（不带参数启动即可关闭端口）。

## 隐私

- 所有数据来自本机：`~/.codex/state_5.sqlite` 与 `rollout-*.jsonl` 会话日志
- 唯一的网络请求是查询**本会话额度占比**，使用本机已登录的 token 发往 `chatgpt.com`，只读
- 统计页会显示每条消息的**前 200 字**用于认出是哪一轮；如果这不可接受，请勿使用
- 不上传任何数据，不含遥测

## 已知限制

- 仅 Windows，且依赖 Codex 桌面版的 DOM 结构；Codex 大改版后需要更新锚点
- 拿不到逐 token 的时间线，所以「最近速度」是按轮次输出估算的
- 部分会话在服务端没有被归属，额度会一直显示 `—`
- 面板的额度有 15 分钟缓存（未归属会话 60 分钟），不是实时的
- 不支持多窗口同时跟随（跟随当前聚焦窗口）

## 常见问题

**快捷方式点了没反应** — Codex 已在运行。完全退出后重试。

**底栏出现了但数字不动** — 看 `%USERPROFILE%\.codex-bar\bar.log` 与 `health.json`；`state` 会告诉你卡在端口、页面、锚点还是数据。

**底栏显示一个点** — 同上，悬停能看到原因；`health.json` 的 `missingAnchors` 会列出 Codex 改版后缺失的元素。

**面板显示 `—`** — 这条对话还没有被服务端统计；不是所有会话都会有额度数据。

**面板数字不更新** — 关闭面板标签页再打开（Codex 会重启面板服务进程）。

## 开发

```
src/bar/       底栏源码
src/shared/    server.py + panel.html（底栏与面板共用，只维护一份）
src/plugin/    面板插件清单
tools/         安装器、卸载器、路径渲染
verify/        回归套件与单元测试
build.ps1      src → dist → 发布包（含逐文件 SHA-256 清单）
```

```powershell
./build.ps1                          # 构建并同步到本机运行位置
./build.ps1 -NoMirror                # 只出 dist
./verify/run-all.ps1                 # 回归：语法/一致性/服务端/面板/底栏/单测/安装器
./verify/run-all.ps1 -Snapshot       # 额外保存截图与数值快照
python verify/test_server.py         # 解析层单元测试
./verify/perf-baseline.ps1           # 生成 docs/PERF.md
```

路径使用 `{{node}}` / `{{python}}` / `{{server}}` 占位符，源码不含任何本机绝对路径；构建与安装各自渲染。
